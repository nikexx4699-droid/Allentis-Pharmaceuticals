# Allentis Pharmaceuticals Pvt. Ltd. - Corporate Website

A modern, premium, fully responsive corporate website for **Allentis Pharmaceuticals Pvt. Ltd.**, an Indian pharmaceutical company dedicated to delivering high-quality, WHO-GMP certified, affordable healthcare solutions globally.

## Features
- **Responsive Navigation**: Sticky topbar, mega menu for products, dark/light mode toggle.
- **Interactive Product Catalog**: Live search and instant filtering by categories (Tablets, Capsules, Syrups, Injectables, Ointments, Eye Drops, Pediatric, Nutraceuticals, Ayurvedic).
- **PCD Franchise Hub**: Monopoly rights inquiry form, territory availability request, and interactive ROI investment calculator.
- **Manufacturing & R&D Showcase**: WHO-GMP cleanroom standards, 1.2B annual tablet capacity, and 7-step quality control pipeline.
- **SEO & Performance**: Open Graph metadata, Schema.org JSON-LD structured data, sitemap.xml, and robots.txt.
- **Floating Controls**: Direct WhatsApp messaging, 24x7 phone hotline trigger, scroll-to-top button, cookie consent banner, and live chat assistant drawer.

## Technology Stack
- HTML5 & CSS3 (Custom CSS in `css/style.css`)
- Vanilla JavaScript (`js/script.js`)
- Bootstrap 5
- Font Awesome 6
- Google Fonts (Poppins)
